Анализ данных HeadHunter

Описание проекта

Итоговый проект по анализу данных на Python.

В проекте проводится исследование резюме соискателей HeadHunter, преобразование и очистка данных, анализ распределений признаков и поиск аномальных значений.

Используемые технологии

Python

Pandas

NumPy

Matplotlib

Seaborn

Jupyter Notebook

Данные

Основной датасет dst-3.0_16_1_hh_database.csv имеет размер около 434 МБ и не хранится в GitHub.
[Скачать датасет с Google Диска](https://drive.google.com/file/d/1gPhhmIn1NnFMgrCvdQJYL4o_SNCCAyCD/view?usp=sharing)
Дополнительный файл ExchangeRates.csv находится в репозитории.

Для воспроизведения анализа скачайте основной датасет и разместите его в папке sessionnoe/data/.

Запуск проекта

Установите Python и необходимые библиотеки.

Скачайте основной датасет по ссылке выше.

Откройте Jupyter Notebook из папки sessionnoe.

Выполните ячейки ноутбука последовательно.
